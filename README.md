# Обёртка над Keitaro

Небольшой сервис для тестового задания: создаёт кампанию в Keitaro и правит офферы в уже существующей кампании.

Кампания создаётся с ротацией по позиции и двумя потоками:

1. `Google` — фильтр по странам из формы, редирект на `https://google.com`.
2. `Offers` — без фильтра, трафик уходит на выбранный оффер. Доли нескольких офферов в сумме всегда равны 100.

У кампании задаются домен, группа и источник из Admin API. Названия новых кампаний должны начинаться с `test_plaskin_`.

## Стек

- Backend: FastAPI, SQLAlchemy, Alembic, SQLite
- Frontend: React, TypeScript, SCSS, Vite

Секреты лежат только в `backend/.env`. Этот файл не коммитится.

## Подготовка

Нужны Python 3.12+ и Node.js.

Ключ Keitaro: админка → профиль → вкладка «API ключи». Скопируйте `backend/.env.example` в `backend/.env` и вставьте ключ:

```text
KEITARO_BASE_URL=https://tlgk.host
KEITARO_API_KEY=ваш-ключ
```

`DATABASE_URL` можно оставить пустым. Тогда база будет файлом `backend/data/app.db`.

## Миграции

Из папки `backend`, после установки зависимостей:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
```

`alembic upgrade head` создаёт таблицу `campaign_records`. В ней хранится локальная запись о кампаниях, созданных этим сервисом: id в Keitaro, название, гео, оффер, домен, группа, источник и id потоков. Сами потоки и доли офферов живут в Keitaro.

Откат миграции: `alembic downgrade base`.

## Запуск

Два процесса.

Backend из папки `backend` с активированным виртуальным окружением:

```bash
uvicorn app.main:app --reload --port 8000
```

Frontend из корня репозитория:

```bash
npm install
npm run dev
```

Интерфейс: [http://localhost:5173](http://localhost:5173). Vite проксирует `/api` на порт 8000.

Проверка чистых функций долей и гео:

```bash
pytest
```

Команду нужно запускать из папки `backend`.

## Как пользоваться

**Создать.** Название с префиксом `test_plaskin_`, гео-коды через запятую (`AU` или `MX, AU`), оффер из поиска, домен, группа и источник. По умолчанию выбираются группа и источник `FORTESTS` и единственный доступный домен.

**Редактор.** Открывает любую кампанию из трекера. Добавление, удаление и возврат оффера меняют локальный черновик: поток подсвечивается, пока изменения не отправлены. «Отправить в Keitaro» публикует активные офферы и их доли. «Отменить» откатывает черновик к последней публикации. «Обновить из Keitaro» забирает текущий состав из трекера; оффер, которого там больше нет, остаётся серым в архиве.

Доли активных офферов в сумме равны 100. Удалённый оффер получает 0 и в сумму не входит. Закреплённая доля не двигается. Остаток делится поровну между остальными, лишние проценты достаются последним: три оффера это 33, 33 и 34, закреплённые 25 и ещё два оффера это 25, 37 и 38.
